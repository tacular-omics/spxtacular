# Citation

If you use spxtacular in your research, please cite the archived software release.

**DOI:** [10.5281/zenodo.19342437](https://doi.org/10.5281/zenodo.19342437)

This is the Zenodo concept DOI. It always resolves to the latest release, and the Zenodo page
lists a version-specific DOI for each release if you need to cite an exact version.

```bibtex
@software{spxtacular,
  author  = {Garrett, Patrick T. and Yates III, John R.},
  title   = {spxtacular: Mass spectrometry spectrum processing in Python},
  doi     = {10.5281/zenodo.19342437},
  url     = {https://github.com/tacular-omics/spxtacular},
  license = {MIT}
}
```

The citation metadata lives in
[`CITATION.cff`](https://github.com/tacular-omics/spxtacular/blob/main/CITATION.cff). GitHub's
"Cite this repository" button on the
[repository page](https://github.com/tacular-omics/spxtacular) generates APA and BibTeX from it,
including the version number of the current release.
